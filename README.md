## 项目列表

### [RandomNumberSystem](RandomNumberSystem/)

一个使用 Python 标准库编写的桌面随机抽数工具，带图形界面、抽取动画、历史记录和命令行模式。适合课堂点名、抽奖、随机分组等场景。
