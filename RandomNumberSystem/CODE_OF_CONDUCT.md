# 贡献者公约

## 我们的承诺

为了营造一个开放、友好、无骚扰的社区，我们承诺：无论年龄、体型、可见或不可见的残障、族裔、性别认同与表达、经验水平、教育背景、社会经济状况、国籍、外貌、种族、宗教或性取向如何，参与本项目的每个人都应获得尊重的对待。

## 我们鼓励的行为

- 使用友好、包容的语言。
- 尊重不同的观点、经验和表达方式。
- 对代码和想法提出具体、可操作的反馈，而不是攻击个人。
- 承认错误，向受影响的人道歉，并从中学习。
- 关注对整个社区最有利的事情。

## 不可接受的行为

- 带有性暗示的言语、图像或不受欢迎的性关注。
- 侮辱、贬低、人身攻击、政治攻击或煽动性言论。
- 公开或私下的骚扰、跟踪、威胁。
- 未经许可公开他人的私人信息，例如住址、邮箱、账号或照片。
- 在专业场合中其他合理认定为不当的行为。

## 适用范围

本公约适用于项目的所有空间，包括 Issue、Pull Request、Discussion、代码评论，以及代表项目参与的其他公开场合。

## 执行

如果你遭遇或目击不可接受的行为，请通过 GitHub 联系维护者 [@Hector-George](https://github.com/Hector-George)。请尽量提供时间、地点、相关链接和经过；维护者会尊重报告者的隐私，并尽快处理。

维护者有权删除、编辑或拒绝不符合本公约的评论、提交、代码和 Issue，并视情况警告、临时封禁或永久禁止参与者。

## 归属

本公约参考 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 编写，并结合本项目情况进行了精简。
