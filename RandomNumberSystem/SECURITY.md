# 安全策略

## 支持范围

当前维护的是 `main` 分支上的最新版本。旧版本不单独接收安全修复。

## 报告安全问题

请**不要**在公开 Issue 中披露安全漏洞。

优先使用 GitHub 的私密漏洞报告功能：

1. 打开 <https://github.com/Hector-George/Bonus/security/advisories/new>
2. 描述漏洞、影响范围、复现步骤和建议修复方式
3. 如果可能，附上最小复现脚本或截图

如果上述入口暂时不可用，请先通过 GitHub 联系维护者 [@Hector-George](https://github.com/Hector-George)，不要在公开 Issue 中披露细节。

维护者会尽快确认收到报告，并在修复发布后公开致谢（如果你愿意署名）。

## 本项目关注的安全问题

- 抽取逻辑被操纵或产生可预测结果
- 历史记录、剪贴板或界面中的敏感信息泄露
- 通过号码范围、数量等输入触发的崩溃或资源耗尽
- 依赖或构建流程中的供应链风险

本项目没有第三方运行依赖，也不联网、不收集用户数据，因此常规攻击面较小。但仍欢迎报告任何你认为可疑的问题。
